## 過去の講演との関係 ― 何を「一歩」加えたか

| 講演 | 結論 |
| --- | --- |
| A「沈まないための備え ― ダメージコントロールとしてのセキュリティ」（全社研修 55分） | 脆弱性ゼロは目標にならない。**やられても事業が止まらない**ことを目標にし、訓練で手に入れる |
| C「生成AIの先へ：AIエージェント時代のサイバーセキュリティ戦略」（2026-05-25 鹿児島 45分） | **作業はAI、判断は人**。判断をその場で作る組織は追いつけないので**判断を設計する**（招集・停止・公表の条件、優先順位、判断責任）。3点セット＝見える化・境界設計・判断訓練 |
| B FIT2026 CN-006「不確実性対応型AIシステム人材の予備的検討」（2026-09-02） | 律速点は人の判断と説明へ移る。AI出力を**検証すべき仮説**として扱い、事業継続判断へ変換する人材（五要素）を育てる |
| **今回** | C の「作業はAI、判断は人」から一歩進めて、**AIを判断の場に入れる（決める権限と責任は人に残す）**。あわせて、C で「何を設計するか」として挙げた境界設計と判断設計を、**限られた人員でも使える書式**にする |

C とかなり重なるため、**C で扱った内容は復習として短く触れ、今回の新しい中身を厚くした。**

| 一歩 | スライド | 内容 | 過去講演との関係 |
| --- | --- | --- | --- |
| ① AIを判断の「相手」にする | p10 | 選択肢を並べさせる／反対の立場から問わせる／見落とした前提を挙げさせる | C の「作業はAI、判断は人」は保ったまま、判断の場にAIを参謀として置く。反対意見を言ってくれる同僚がいない少人数の組織ほど効く |
