## 方針

- 初めて聞く人を前提にする。過去の講演には触れない
- 冒頭で結論を3つ示し、最後に同じ3つを「明日からやること」として示して閉じる
- 途中に会場参加のミニ演習（挙手）を1つ入れる
- 数値や固有の事件名は入れていない（入れる場合は時点と出典を明記する）

## 構成と時間配分（30分）

台本は約6,500字。1分300字で約22分。挙手、間、スライド送りを含めて30分に収まる想定。

| 経過 | 部 | スライド |
| --- | --- | --- |
| 0:00–0:04 | はじめに | 表紙（自己紹介）、結論を先に、30分の地図 |
| 0:04–0:09 | 第1部 律速点は人の判断へ | 見つけるのは速くなった／5つの判断（止める・続ける・説明する・公表する・何から戻す）／「がんばる」の正体は材料集め |
| 0:09–0:18 | 第2部 AIとともに判断する | 提案① AIを判断の相手にする／AIの出力への4つの問い／**ミニ演習（挙手）**／提案② 暫定判断と見直し時刻 |
| 0:18–0:23 | 第3部 限られた人員で回す | 判断が人に貼りつく弱さ／提案③ 任せ方の3段階／提案④ 判断カード |
| 0:23–0:28 | 第4部 平時に判断を練習する | 提案⑤ AIを入れた机上演習／演習で測るもの（押したら飛ばす） |
| 0:28–0:30 | まとめ | 持ち帰っていただきたい3つ |

付録（配布用）：判断カード雛形、AIを入れた机上演習の進行雛形（90分）。
