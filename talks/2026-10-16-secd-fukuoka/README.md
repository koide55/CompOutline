## 過去の講演との関係 ― 何を「一歩」加えたか

| 講演 | 結論 |
| --- | --- |
| A「沈まないための備え ― ダメージコントロールとしてのセキュリティ」（全社研修 55分） | 脆弱性ゼロは目標にならない。**やられても事業が止まらない**ことを目標にし、訓練で手に入れる |
| B FIT2026 CN-006「不確実性対応型AIシステム人材の予備的検討」（2026-09-02） | AIで発見が速くなるほど**律速点は人の判断と説明へ**移る。AI出力を**検証すべき仮説**として扱う人材（五要素）を、事業継続体験型演習で育てる |
| **今回** | A と B が「何を目指すか」「どんな人を育てるか」を示したのに対し、**判断そのものを組織の仕組みとして平時に設計する方法**を示す |

今回新しく加えたのは次の4つ（スライドの kicker に「一歩①〜④」と表示）。

1. **任せ方の3段階**（p11）― 「取り消せるか／影響はどこまでか／後で説明できるか」の3つで、AIに任せる作業を「自動／人の承認つき／人が決める」に分けておく。B の「AI利用を禁止／許可の二択にしない」を運用規則にしたもの
2. **暫定判断と見直し時刻**（p12）― 不確実なときの失敗を「過信」と「先送り（過剰な拒否を含む）」の2つに整理し、「今の材料でこう決める／○時に見直す／覆す条件」を記録する型を示す。B の評価観点「過信と過剰な拒否の両方を観察」を現場の判断に落としたもの
3. **判断カード**（p16、付録1）― 5つの判断（止める・続ける・説明する・公表する・何から戻す）ごとに、決める人／代わり／材料／任せ方／期限と見直し／伝える先／頼る先を1枚にする。A の「最初に決める3つ」の次に書くもの
4. **AIを入れた机上演習**（p19、付録2）― AI に「状況をまとめる役」「状況を揺さぶる役」「記録を残す役」を持たせ、準備と記録の負担を下げて小さな組織でも回せるようにする。A の付録2（2時間版）を90分に縮めて AI の3役を入れた
