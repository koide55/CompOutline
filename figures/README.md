# 図の管理

## 方針

**第三者著作物は一切使わない。** すべての図はこのリポジトリで新規に作成する。
製品写真、報道写真、他サイトから引用した図表、書籍のスキャンは載せない。

写真でしか説明できないと思える題材（基板、コネクタ、ディスクの内部など）は、
たいてい模式図のほうが要点が伝わる。写真を探す前に、
**「この図で読者に何を分からせたいのか」を1文で書く**こと。それが図の仕様になる。

## 図の書き方（本文中）

講義ノート本文には、図そのものではなく**図の仕様**を引用ブロックで置く。

```markdown
> **[図 1-2] チューリングマシンの構成**
> 左右に無限に伸びるテープ、その1マスを指すヘッド、状態を持つ有限制御部の3要素を描く。
> 制御部からヘッドへ「書け／動け」、ヘッドから制御部へ「読んだ記号」の矢印を通し、
> 「読む→書く→動く→状態を変える」が1ステップであることを示す。
```

図番号は `第N回-連番`。本文の登場順に振る。

この形式にしておくと、(1) 図がまだ無くてもノートとして読める、
(2) 仕様と図が離れないので描き直しが効く、(3) 一覧を機械的に集められる。

一覧の生成:

```bash
python3 tools/collect_figures.py
```

## 作図の実装

| 種別 | 手段 |
| --- | --- |
| 構成図・階層図・フロー | `tools/figs/` に Python で書き、SVG を出力 |
| 回路図・タイミング図 | 同上 |
| グラフ・プロット | 同上（軸や曲線も `svgkit.py` の部品で描く） |
| 表で足りるもの | 図にせず本文の表にする |

**全60点が `tools/figs/*.py` の1本道で生成される。** 手で書いた SVG も、
Mermaid などの外部記法も混ぜていない。共通のスタイルと描画部品は
`tools/svgkit.py` にあり、配色や線の太さの変更はそこ1箇所で全点に効く。

| ファイル | 担当 |
| --- | --- |
| `tools/figs/lec01_04.py` | 第1〜4回 |
| `tools/figs/lec05_08.py` | 第5〜8回 |
| `tools/figs/lec09_11.py` | 第9〜11回 |
| `tools/figs/lec12_13.py` | 第12〜13回 |

```bash
python3 tools/build_figures.py     # 全点を figures/ に書き出す
python3 tools/preview.py           # PNG のコンタクトシートで目視確認
```

出力は `figures/fig-NN-MM.svg` に統一する。SVG にするのは、
スライドにも印刷物にも解像度を気にせず載せられるため。
スライドに貼るときは `slides/tools/figs2png.sh` で PNG に落とす。

### スタイル

- 文字は図の中でも本文と同じ書体・サイズ感にする（図だけ極端に小さくしない）
- 色は情報を担わせない。白黒印刷とプロジェクタの色ずれで壊れるため、
  区別は**形・線種・ラベル**でつける。色は補助にとどめる
- 1つの図に詰め込まない。要素が7つを超えたら図を分ける
