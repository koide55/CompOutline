## 4. 配布・公開上の制約

**GitHub Public 化にあたっての障害が2つある。**

### (1) ファイルサイズ

GitHub は1ファイル100MBを超えるとプッシュを**拒否**する（警告ではなくエラー）。

- `CompOutline2024.pptx`: 148.7 MB — 制限超過
- `network2026.pptx`: 123.6 MB — 制限超過

一度コミットすると履歴に残り、後から `.gitignore` に追加しても消えない
（`git filter-repo` 等での履歴書き換えが必要になる）。
このため**現時点では両ファイルを `.gitignore` に入れ、コミットしていない**。

対応案:

| 案 | 内容 | 見込みサイズ | 備考 |
| --- | --- | --- | --- |
| A | メディアを再圧縮（TIFF/PNG → JPEG、EMF → PNG） | 30〜40 MB | 画質劣化は軽微。最も素直 |
| B | セクション単位で分割（例: ネットワーク編、ハードウェア編…） | 各10〜30 MB | 講義回ごとの配布にもなる。Aと併用可 |
| C | Git LFS を使う | — | GitHub 無料枠は1GB/月。148MB×版数ですぐ枯渇する |
| D | pptx は配布せず PDF のみ公開 | 数MB | 編集履歴が追えなくなる |

推奨は **A + B**。A で 100MB 制限を確実に回避し、B で1ファイルあたりの
差分レビューを現実的なサイズにする。

### (2) 第三者著作物

公開リポジトリに置く場合、以下は権利処理の確認が必要:

- 新聞紙面のスキャン画像（読売新聞2012.2.15夕刊、毎日新聞2012.2.19朝刊）
- テレビ番組の取材写真
- Web から引用した図（Google データセンター写真、labellerr.com、eaglys.co.jp、
  Wikipedia 由来の図など）
- 製品写真（CPU、マザーボード、各種インターフェースなど）

学内講義での利用は著作権法35条の範囲だが、**インターネット公開は同条の対象外**。
出典明記だけでは足りないケースがあるので、公開版では差し替えか削除を検討する。
