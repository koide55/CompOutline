# 演習を Moodle に載せるときの設定

全13回・計102問を、回ごとの小テストとして Moodle にインポートできる XML に変換してある。

| | Moodle の問題数 | 配点 | 採点 |
| --- | ---: | ---: | --- |
| **数値問題**（Numerical） | 2問 | 2点 | 自動 |
| **穴埋め問題**（Cloze） | 15問 | 45点 | 自動 |
| **作文問題**（Essay） | 89問 | 89点 | 手採点 |
| 合計 | **106問** | **136点** | |

演習は102問だが Moodle の問題は106問になる。4問（4-7・6-4・8-4・12-2）が
数値の部分と作文の部分に分かれるためである（→「1問が2つに分かれるもの」）。

数値だけを答える問題は自動採点に回した。Moodle の数値問題は1問1答なので、
複数の値を答える15問は穴埋め問題にしてある。中身は数値の欄なので、
自動採点されることは変わらない。

最終確認: 2026-09-22

## インポートの手順

```bash
node moodle/build-xml.js
```

`moodle/xml/` に14ファイルができる。

| ファイル | 中身 |
| --- | --- |
| `第01回_計算とは何か.xml` … `第13回_….xml` | その回の演習だけ（回ごとに入れるとき） |
| `全13回.xml` | 106問すべて（一度に入れるとき） |

Moodle で

1. コース → 問題バンク → インポート
2. ファイル形式に **Moodle XML 形式** を選ぶ
3. ファイルを上げる

XML の先頭にカテゴリ指定が入っているので、問題は
`コンピュータシステム通論/第01回 計算とは何か` のように**回ごとのカテゴリに
自動で振り分けられる**。`全13回.xml` を1本入れても13カテゴリに分かれる。

そのあと小テストを13個作り、各回のカテゴリから問題を追加する。

### 各回の最大評点を10点に揃える

**これは小テスト（活動）の設定で、問題バンクの XML には入らない。**
Moodle XML の問題形式は問題そのものしか運べないため、回ごとに手で入れる。

各回について

1. 小テスト → **問題** を開く（設定画面ではない）
2. 右上の **最大評点** に `10` を入れて **保存**

手順の詳しい版は [moodle-setup.md](moodle-setup.md) にある。

これだけで、素点の合計（回によって 6〜16点）が10点満点に比例換算される。
13回すべてに入れること。1回でも忘れると、その回だけ重みが変わる。

| 回 | 素点 | 自動 | 手採点 | 換算係数 | 素点1点の価値 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 13 | 9 | 4 | 0.769 | 0.769点 |
| 2 | 9 | 5 | 4 | 1.111 | 1.111点 |
| 3 | 8 | 3 | 5 | 1.250 | 1.250点 |
| 4 | 10 | 1 | 9 | 1.000 | 1.000点 |
| 5 | 12 | 7 | 5 | 0.833 | 0.833点 |
| 6 | 16 | 13 | 3 | 0.625 | 0.625点 |
| 7 | 9 | 0 | 9 | 1.111 | 1.111点 |
| 8 | 11 | 4 | 7 | 0.909 | 0.909点 |
| 9 | 12 | 3 | 9 | 0.833 | 0.833点 |
| 10 | 6 | 0 | 6 | 1.667 | 1.667点 |
| 11 | 8 | 0 | 8 | 1.250 | 1.250点 |
| 12 | 12 | 2 | 10 | 0.833 | 0.833点 |
| 13 | 10 | 0 | 10 | 1.000 | 1.000点 |

`node moodle/build-xml.js` を走らせるとこの表が出るので、
演習を足したり消したりしたあとは作り直して確認すること。

### 素点を10点ぴったりにはできない

穴埋め問題の配点は欄ごとに1点で、**整数しか指定できない**
（Cloze の `{1:NUMERICAL:…}` の先頭の数字が重み）。
第6回は穴埋めの欄だけで10個あるので、そこに作文問題3問を足すと必ず10点を超える。
だから素点をそろえるのではなく、最大評点で換算する。

### 回の中での重みは偏っている

最大評点で換算しても、**回の中でどの問題が効くか**は変わらない。

- **第6回は自動採点が81%**（6-1〜6-4 の数値だけで16点中13点）。
  RAID とバックアップの違い（6-5）や SSD のデフラグ（6-6）が3点しかない
- **第7回・第10回・第11回・第13回は自動採点が0%**。全部が手採点
- **第4回は自動採点が10%**（4-7 の1点だけ）

数値を解く力と、理由を説明する力の比重を回ごとにそろえたいなら、
作文問題の配点（`moodle/essay.js` の既定は1点）を上げるとよい。
たとえば作文を3点にすると第6回は 13:9 になり、ほかの回とも近づく。
**今は既定の1点のままにしてある**（配点は講義の重み付けの判断なので）。

## 生成のしくみ

設問の文章は `lectures/*.md` の演習節から抜き出している。
**文面を直すのはノート側だけでよい。**

| ファイル | 持っているもの |
| --- | --- |
| `lectures/*.md` | 設問の文章（唯一の出どころ） |
| `moodle/numeric.js` | 自動採点にする問題の解答欄・正解・許容誤差 |
| `moodle/essay.js` | 作文問題の解答形式・添付・分割・問題名 |
| `moodle/build-xml.js` | 上を合わせて XML を書き出す |

Markdown の表・コードブロック・箇条書きは HTML に変換される。
問題名は `moodle/essay.js` の `names` にあり、抜けがあると生成時に警告が出る。

### 1問が2つに分かれるもの

数値の部分だけを自動採点にし、残りは**作文問題として別に作る**。
Moodle の穴埋め問題に作文の欄は置けないため。
設問文はどちらにも同じものが出るので、学生には「この問題では〜を答える」と
XML 側に断り書きが入っている。

| 問 | 自動採点 | 別に作る作文問題 |
| --- | --- | --- |
| 4-7 | 最小の試行回数（7回） | その方法（二分探索） |
| 6-4 | パリティ P | A, C, P から B を復元する計算 |
| 8-4 | (a) と (b) | (c) 何を支払っているか |
| 12-2 | n=1000 の鍵の数 | 鍵配送問題とは何か／一般の式 |

## 作文問題のまま残した2問

数値は付随的で、本体が作文でしか採点できない。自動採点に移すと問題が壊れる。

| 問 | 理由 |
| --- | --- |
| 3-5 | 本体は命令列を書くこと。命令数（9命令）だけ取り出しても意味がない |
| 7-5 | 本体はシステムコールを順に挙げること。パイプの本数（2本）は付随的 |

## 作文問題の設定

**XML に入っているので、Moodle で設定し直す必要はない。**
以下は何がそうなっているかの控えである。変えたいときは `moodle/essay.js` を直す。

### 既定

| 項目 | 値 |
| --- | --- |
| 解答形式 | HTML エディタ（`editor`） |
| 解答欄の行数 | 12行 |
| 添付ファイル | 許可しない |
| 配点 | 1点・手採点 |

### 解答形式を「書式なしテキスト（等幅フォント）」にしたもの

コードや SQL を書かせる問題。HTML エディタのままだと**改行とインデントが崩れて
採点できない**。

| 問 | 中身 |
| --- | --- |
| 1-2 | チューリングマシンの遷移規則 |
| 3-1 | NAND で XOR（ゲートの式） |
| 3-5 | 命令列 |
| 4-5 | C のコードの誤りの指摘 |
| 6-4 | 復元の計算（上の分割分） |
| 7-9 | Python の `withdraw` の修正 |
| 11-2 (b) | 表の分割（表名と属性の列） |
| 11-3 | SQL 3本 |
| 11-4 | SQL 1本 |
| 12-8 | SQL インジェクションの修正 |

### 添付ファイルを1個まで許可したもの

手で描いた図の写真を受け付ける。テキストでも書けるようにしてあるので、添付は任意。

| 問 | 中身 |
| --- | --- |
| 3-1 | 回路図 |

## 気をつけること

- **許容誤差**は `moodle/numeric.js` の `tol` にある。5-3 は「概算せよ」なので1割ほど、
  他は四捨五入の幅だけ取ってある。実際に学生の解答を見て狭すぎたら、ここを直して
  XML を作り直す
- **単位**は解答欄のラベル側に書いてある（Moodle の単位入力は使っていない）。
  学生は数値だけを入れる
- **6-1 と 6-2** は 1KB=1000バイト、1MB=10⁶バイトという断りをノートに入れた。
  これがないと答えが一意に決まらず、自動採点できない
- **`moodle/xml/` は生成物**。手で直しても次の生成で消える。
  設問の文面はノート、解答欄は `moodle/numeric.js`、
  解答形式と問題名は `moodle/essay.js` を直すこと
- **穴埋め問題の部分点**は欄ごとに1点で、Moodle が自動で合計する。
  `defaultgrade` は書き出していない（Moodle が欄数から決める）
