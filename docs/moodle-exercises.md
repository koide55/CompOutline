# 演習を Moodle に載せるときの設定

全13回・計102問を、すべて **作文問題**（Essay / 手採点）として出す方針である。
ポートフォリオと同じ画面で扱えるので、提出物が1種類で済む。

その代わり、以下2点の手当てが要る。**Moodle に問題を作る前にこの文書を読むこと。**

- 既定の設定では書けない問題が9問ある（→「既定から変える問題」）
- 答えが一意の数値を問う問題が19問あり、これは全部が手採点になる（→「数値の問題」）

最終確認: 2026-09-22

## 既定の設定

とくに断りのない93問は、これで載る。

| 項目 | 値 |
| --- | --- |
| 問題タイプ | 作文問題 |
| 解答形式 | HTML エディタ |
| 添付ファイル | 許可しない |
| 評点 | 手採点 |

## 既定から変える問題

### 解答形式を「書式なしテキスト（等幅フォント）」にする

コードや SQL を書かせる問題である。HTML エディタのままだと**改行とインデントが
崩れて採点できない**。

| 問 | 中身 |
| --- | --- |
| 1-2 | チューリングマシンの遷移規則 |
| 3-1 | NAND で XOR（ゲートの式） |
| 3-5 | 命令列 |
| 4-5 | C のコードの誤りの指摘 |
| 7-9 | Python の `withdraw` の修正 |
| 11-2 (b) | 表の分割（表名と属性の列） |
| 11-3 | SQL 3本 |
| 11-4 | SQL 1本 |
| 12-8 | SQL インジェクションの修正 |

### 添付ファイルを1個まで許可する

手で描いた図の写真を受け付ける。テキストでも書けるようにしてあるので、
添付は任意である。

| 問 | 中身 |
| --- | --- |
| 3-1 | 回路図 |

## 数値の問題

答えが一意に定まる19問。作文問題にすると自動採点の利点を捨てることになる。
受講者50人なら、1学期で700〜900箇所の数値を手で確認することになる。

そのため、演習節の冒頭に**「数値を答える問題は、答えだけでなく計算の過程も
書くこと」**と断り書きを置いた。過程を書かせれば作文問題として自然になり、
答えが違っても部分点を付けられる。

| 回 | 問 | 答え |
| ---: | --- | --- |
| 1 | 1-1 | (252,105,42) (105,42,21) (42,21,0) → 21 |
| 2 | 2-1 | `10101101` / `11010011` |
| 2 | 2-2 | 1.82 TB |
| 2 | 2-4 | 100秒 / 約13.3秒 |
| 3 | 3-4 | 36mm / 届く / 6.4GHz |
| 3 | 3-5 | 9命令 |
| 4 | 4-7 | 7回 |
| 5 | 5-2 | 3.96ns / 11.8ns / 約3倍 |
| 5 | 5-3 | (a) 約131,000回 / (b) 約1,050,000回 |
| 5 | 5-5 | 2.5倍 / 5倍 |
| 6 | 6-1 | 約8.03ミリ秒 / 転送は約0.4% |
| 6 | 6-2 | 約4.0秒 / 約24ミリ秒（約170倍） |
| 6 | 6-3 | RAID 5 は 20TB・1台 / RAID 6 は 16TB・2台 |
| 6 | 6-4 | P = `0001` |
| 6 | 6-7 | 66.7% / 4台 / 2倍 |
| 7 | 7-5 | パイプ2本 |
| 8 | 8-4 | 16×16 = 32本 / 8分の1 |
| 9 | 9-8 | .128 / .191 / 62個 |
| 12 | 12-2 | 499,500個 / 2,000個 |

負担が重いと分かった時点で、この19問だけ **数値問題** か **Cloze（穴埋め）**
に移すとよい。移す場合も、上の断り書きのおかげで設問の文面はそのまま使える。

## 全問が作文向きの回

第10回（6問）と第13回（10問）は、数値も図もコードもなく、
「なぜか説明せよ」「反論せよ」型で揃っている。**ここから作り始めるのが楽である。**
第12回（12-8 を除く9問）、第7回（7-5・7-9 を除く7問）もほぼ同じ。
