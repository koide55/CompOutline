# Moodle に演習を載せる手順

`moodle/xml/` の XML を Moodle に入れ、13回分の小テストを動く状態にするまでの手順。
開講前に一度だけ行う作業と、毎週の作業に分けてある。

問題の中身は [moodle-exercises.md](moodle-exercises.md) を見ること。

対象: Moodle 4.x / 5.x。3.x はメニューの場所が違う（後述）。
最終確認: 2026-09-22

---

## 開講前にやること

### 0. 準備

- [ ] Moodle にコースがあり、自分が**教師**ロールである
- [ ] 手元で XML を作る

```bash
node moodle/build-xml.js
```

`moodle/xml/` に14ファイルができる。最後に出る換算表は、あとで最大評点を
入れるときに使うので残しておくこと。

### 1. 問題バンクにインポートする（1回だけ）

1. コースを開く → 上部タブの **その他** → **問題バンク**
   （Moodle 3.x は 歯車 → コース管理 → 問題バンク）
2. 左上のメニューから **インポート** を選ぶ
3. **ファイル形式** で **Moodle XML 形式** を選ぶ
4. `moodle/xml/全13回.xml` をドラッグ＆ドロップ
5. **インポート** を押す

**106問をインポートしました** と出れば成功。**続ける** を押す。

- [ ] 問題バンクのカテゴリ一覧に、`第01回 計算とは何か` から
      `第13回 機械学習からLLM・エージェントAIへ` まで**13個**できている
- [ ] 各カテゴリの問題数が下の表と合っている

| 回 | 問題数 | 回 | 問題数 |
| ---: | ---: | ---: | ---: |
| 1 | 5 | 8 | 8 |
| 2 | 7 | 9 | 10 |
| 3 | 6 | 10 | 6 |
| 4 | 10 | 11 | 8 |
| 5 | 8 | 12 | 11 |
| 6 | 8 | 13 | 10 |
| 7 | 9 | | |

回ごとに入れたいときは `全13回.xml` の代わりに `第01回_….xml` を13回に分けて
上げてもよい。振り分けられるカテゴリは同じである。

### 2. 小テストを1つ作る（第1回で試す）

1. コース → 週/トピックの **活動またはリソースを追加** → **小テスト**
2. **名称** に `第1回 演習` と入れる
3. 設定を次のようにする

| 欄 | 値 | 理由 |
| --- | --- | --- |
| タイミング → **小テスト公開** | その回の講義日 | |
| タイミング → **小テスト終了** | 講義日の**1週間後** | 締切は出題から1週間（第1回ガイダンス） |
| タイミング → **制限時間** | 無効 | 持ち帰りの課題なので計らない |
| タイミング → 時間切れの場合 | 自動的に送信する | 書きかけを失わせない |
| 評点 → **受験可能回数** | 1回 | |
| 問題の挙動 → **問題の動作** | **遅延フィードバック** | ← **重要**（下記） |
| 復習オプション → **受験中** / **受験直後** | すべてのチェックを**外す** | ← **重要**（下記） |
| 復習オプション → **小テスト終了後** | 「得点」「正解」「全体フィードバック」を入れる | 締切後に答え合わせできる |
| 評定 → **完了トラッキング** | 「学生は活動を完了する必要がある」＋**受験を完了する** | **提出＝出席**の記録になる |

4. **保存して表示** を押す

> **なぜ遅延フィードバックなのか**
>
> 自動採点の17問は、その場で正誤が出る設定にすると、早く出した学生から
> 正解が回る。遅延フィードバックなら、採点は提出後に行われ、
> 学生には締切まで結果が見えない。

> **なぜ復習オプションを絞るのか**
>
> 既定のままだと受験直後に正解が表示される。上と同じ理由で、
> 「小テスト終了後」だけに寄せる。

### 3. 問題を入れて、最大評点を10にする

1. 作った小テストを開く → **問題** タブ
2. **追加** → **問題バンクから**
3. カテゴリで `第01回 計算とは何か` を選ぶ
4. 見出しのチェックボックスで**全選択** → **選択した問題を小テストに追加する**
5. 右上の **最大評点** に `10` と入れて **保存**

- [ ] 問題が5問並んでいる
- [ ] ページ下の合計が **13.00**（素点）になっている
- [ ] **最大評点** が **10.00** になっている

素点13点が10点に換算される。素点は回によって 6〜16点と違うが、
**最大評点をどの回も10にすれば、13回が同じ重みになる**。

> **最大評点は「設定」画面には無い。** 小テストの **問題** タブの右上にある。

### 4. 学生の見え方を確かめる

1. 小テストのページ → 右上メニュー → **プレビュー**
2. 次を目で見る

- [ ] 図や表が崩れていない（7-7・9-9・11-2 に表がある）
- [ ] コードが等幅で、インデントが残っている（4-5・7-9・12-8）
- [ ] 数値問題・穴埋め問題の入力欄が出ている
- [ ] 分割した問題に「この問題では〜を答える」の断り書きが出ている
      （4-7・6-4・8-4・12-2）

第4回・第7回・第11回・第12回のプレビューも見ておくとよい。
表・コード・SQL・分割がひととおり入っている。

### 5. 残り12回を作る

第1回の小テストを複製すると、設定を入れ直さずに済む。

1. コース → 第1回の小テストの **編集** → **複製**
2. 複製したものの **設定を編集** で、名称・公開日・終了日を直す
3. **問題** タブ → 第1回の問題をすべて削除 → その回のカテゴリから追加
4. **最大評点** に `10` を入れて保存

- [ ] 13個そろった
- [ ] 13個すべてで最大評点が **10.00**
- [ ] 13個すべてで公開日と終了日が正しい
- [ ] 13個すべてで問題の動作が **遅延フィードバック**

素点の合計が回ごとに下の表と合っていれば、問題の入れ忘れがない。

| 回 | 素点 | 回 | 素点 | 回 | 素点 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 13 | 6 | 16 | 11 | 8 |
| 2 | 9 | 7 | 9 | 12 | 12 |
| 3 | 8 | 8 | 11 | 13 | 10 |
| 4 | 10 | 9 | 12 | | |
| 5 | 12 | 10 | 6 | | |

### 6. ポートフォリオ

毎回ポートフォリオを出してもらう（今回の問いへの答え／分からなかったこと、
200文字以上）。**これは Moodle 側で手で作ってある**（2026年度）。

このリポジトリは**演習102問だけ**を生成する。ポートフォリオは
`moodle/xml/` にも `moodle/essay.js` にも入っていないので、
**コースを次年度にコピーするときは、ポートフォリオが一緒に移ったかを確かめること。**
演習は XML を入れ直せば復元できるが、ポートフォリオは手作業の分が失われると
作り直しになる。

小テストの中に入れた場合は、その回の素点がポートフォリオの配点だけ増える。
下の素点の表は演習だけの値なので、照合するときはその分を足して見ること。

## 毎週やること

### 締切後の採点

1. 小テスト → **結果**（または 受験結果）
2. 左上メニューから **手動評定**
3. **未採点のみ** で絞る
4. 作文問題だけが出るので、点を付けてコメントを書く

自動採点の17問は提出時に採点済みなので、ここには出ない。
手採点の分量は回によって 3〜10問ぶんである（→ [moodle-exercises.md](moodle-exercises.md)）。

### 出席

完了トラッキングを入れてあれば、**コース → レポート → 活動完了** で
誰が出したかが一覧で見える。これが出席簿になる。

## 詰まったとき

| 症状 | 見るところ |
| --- | --- |
| インポートで「問題が見つかりません」 | ファイル形式が **Moodle XML 形式** になっているか。GIFT や Aiken ではない |
| カテゴリが1つもできない | XML の先頭の `<question type="category">` が消えていないか。`moodle/xml/` は生成物なので、手で直さず作り直す |
| 数値問題で、合っているのに不正解になる | 許容誤差が狭い。`moodle/numeric.js` の `tol` を広げて作り直し、問題バンクで入れ替える |
| コードのインデントが崩れる | その問題が `moodle/essay.js` の `monospaced` に入っているか |
| 合計点が表と違う | 問題の入れ忘れか、二重に入れている。**問題** タブで数を数える |
| 学生に正解が早く見えてしまう | 問題の動作が **遅延フィードバック** か。復習オプションの「受験中」「受験直後」が外れているか |
| 演習の文面を直したい | `lectures/*.md` を直して `node moodle/build-xml.js`。問題バンクへ入れ直し、小テストの問題を差し替える |

## 作り直したときの入れ替え

XML を作り直しても、**すでにインポートした問題は自動では更新されない**。

1. 問題バンク → 該当カテゴリの古い問題を削除
   （**すでに受験がある問題は削除できず、非表示になる**。学生の解答は残る）
2. 新しい XML をインポート
3. 小テストの **問題** タブで、古い問題を外して新しいものを追加
4. **最大評点** を `10` に入れ直す（問題を入れ替えると戻ることがある）

**学期が始まってからの差し替えは避けること。** 提出済みの解答と対応が取れなくなる。
直すなら開講前に済ませる。
