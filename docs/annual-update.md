# 毎年の更新箇所

時点によって古くなる記述を、ここに集めてある。
**新年度の資料を作る前に、この一覧を上から確認すること。**

執筆の約束（[curriculum.md](curriculum.md)）のうち
「具体的な数値には時点を書く」を実際に回すための表である。

最終確認: 2026-09-21 / 本文の表記は「2026年時点」

## 使い方

1. 下の表を上から見て、値が変わっていないかを確かめる
2. 変えた箇所は `lectures/` だけでなく、**`slides/decks/` と `assessment/lectures/` にも同じ内容がある**
   （3か所が手書きで重複している。片方だけ直すとずれる）
3. 直したら年の表記（`2026年時点` → 次年度）も一緒に置き換える
4. この文書の「最終確認」の日付を更新する

洗い出しは機械でできる。

```bash
grep -n '20[0-9][0-9]年\|時点' lectures/*.md slides/decks/*.js
```
